# FocUS
## 誰にでも、ではなく、あなたに喜んでもらえる一枚を。

**FocUSは、写真を撮り合うほどに相手の「好き」が分かり、次の撮影がもっと楽しみになるアプリです。**

撮られる側の「自分好みに撮ってほしい」と、撮る側の「相手に喜んでもらいたい」をつなぎます。

## 製品概要

### 背景（製品開発のきっかけ、課題等）

「写真を撮って！」

撮ってもらった写真を見て、「なんか違う」と感じる。
でも、どう撮ってほしいか、自分でもうまく説明できない。
もう一度お願いしたいけれど、撮り直しを頼むのは少し気まずい。

一方、撮る側も、喜んでほしいと思っています。
それでも、何を変えればよいか分からないまま撮り直しを重ねると、負担や「うまく撮らなきゃ」というプレッシャーにつながります。

**どちらにも悪気はないのに、楽しいお出かけの途中で、少しぎすぎすしてしまう。**

私たちは、この経験からFocUSを開発しました。

人物をどのくらい大きく写すか。背景をどのくらい入れるか。どんな表情や雰囲気を残すか。
「いい写真」の基準は、人によって異なります。

だからこそ、相手が実際に選んだ写真を手がかりに、その人の「好き」を少しずつ知っていく仕組みを考えました。

### 製品説明（具体的な製品の説明）

FocUSでは、二人がつながり、撮った写真を共有できます。
撮られた人はお気に入りの写真と理由を選び、撮った人はクイズで相手の好みを予想します。

答え合わせで知った好みは「撮影カルテ」に残り、次の撮影の参考になります。

| ステップ | 体験 |
| --- | --- |
| 1. つながる | 招待コードで相手と接続します。 |
| 2. 撮る・共有する | 続けて撮影し、「撮影終了・共有」で写真をひとまとまりの撮影セッションとして共有します。 |
| 3. 「好き」を返す | 撮られた人が、お気に入りの写真を複数選択し、それぞれに好きな理由を付けて送信します。 |
| 4. 相手の好みを予想する | 撮影者にアプリ内通知が届き、お気に入りの写真を当てる3択クイズに挑戦します。 |
| 5. 次の撮影に生かす | 答え合わせの後に撮影カルテを確認し、撮影ガイドで参考写真や理由を振り返ります。 |

クイズには、お気に入りの中からランダムに選んだ1枚と、お気に入り以外の2枚を使います。
3択を作れない場合も、撮影カルテで相手の「好き」を確認できます。

**撮る。相手の好みを知る。次はこう撮ってみたくなる。**

この繰り返しを、FocUSの中心に置いています。

### 特長

#### 1. 「この写真が好き」で、撮る人にも喜びを返す

お気に入りは、何枚でも選べます。
さらに、「表情」「構図」「人物の大きさ」「背景」「光」「雰囲気」から、好きな理由を選択できます。

いいねは、好みを記録するだけの機能ではありません。

**「あなたが撮ってくれた、この写真が好き」**

その気持ちが撮影者に伝わることで、「喜んでもらえた」「また撮ってあげたい」という気持ちにつながることを目指しています。

#### 2. クイズで、「知っているつもり」に気づく

お気に入りの答えを見る前に、撮影者が相手の好みを予想します。

大切にしているのは、正解率よりも、相手について考える時間です。

「自分はこの写真だと思ったけれど、相手はこちらが好きなんだ」

自分の認識と、実際の相手の好みのギャップを知る。
不正解も、「へえ、こういう写真が好きなんだ。次は試してみよう」という発見につなげます。

#### 3. 相手ごとの撮影カルテで、次の一枚につなげる

相手が選んだ写真と理由を、撮影カルテに蓄積します。
クイズの回答後に確認できるほか、接続後のホームからも開けます。

撮影ガイドでは、理由ごとの参考写真やヒントを見返せます。

毎回細かく指示してもらうだけでなく、撮る人自身が「こう撮ったら喜んでくれるかな」と考えるための手がかりになります。

### 解決出来ること

FocUSは、写真撮影で生まれる次のようなすれ違いの軽減を目指します。

| 撮られる側の悩み | 撮る側の悩み | FocUSによるアプローチ |
| --- | --- | --- |
| 好みをうまく言葉にできない | どんな写真が好きか分からない | 実際の写真と理由を使って、好みを共有する |
| 撮り直しをお願いしづらい | 何を変えればよいか分からない | 過去のお気に入りを、次の撮影の参考にする |
| 気に入ったことを十分に伝えられない | 喜んでもらえたか分からない | いいねとアプリ内通知で「好き」を届ける |

撮られる側は、「自分のことを理解してくれている」とうれしくなる。
撮る側は、自分の写真を喜んでもらえて、また撮りたくなる。

**二人とも撮影を楽しみ、二人とも満足できる写真を残せる体験を目指しています。**

※現在は一連の機能の動作確認まで完了しています。実際の利用による、好みへの理解や撮影時の気まずさの変化については、今後検証します。

### 今後の展望

- **実際のお出かけでの利用検証**
  - 相手の好みへの理解や、撮影を楽しむ気持ちがどう変化するかを確認します。
  - お気に入りの選択やクイズが、負担なく続けられるかを検証します。
- **撮影カルテ・ガイドの改善**
  - 好みの蓄積に応じて、次の撮影で参考にしたい写真を見つけやすくします。
- **画像分析の活用**
  - 将来的には、選ばれた写真の人物の大きさや光などを分析し、より具体的な振り返りを支援することを検討します。
  - 「好き」の判断は本人の選択を軸にします。
- **実利用に向けた環境整備**
  - 現在のローカルデモ環境から、スマートフォンで継続利用できる環境への移行を進めます。

### 注力したこと（こだわり等）

#### 「誰にでも」より、「あなたに」

一般的な撮影技術に加え、目の前の相手ならではの好みを知ることを大切にしました。
本人が選んだ写真を軸に、相手ごとのカルテをつくっています。

#### 指摘ではなく、「好き」を起点にする

撮られた側が不満を伝えるだけでは、撮る側の負担になってしまうことがあります。
そこで、気に入った写真を選んで返すことを起点にしました。

撮る側にも「自分が撮った写真を好きと言ってもらえた」という喜びが届く設計を目指しています。

#### 撮影の記憶が鮮明なうちに振り返る

実装では、二人の画面間で情報をリアルタイムに受け渡すことに力を入れました。

撮影したときの状況や気持ちを覚えているうちに、自分の予想と相手の好みを照らし合わせられるよう、お気に入りの送信から通知、クイズ、撮影カルテまでをつなぎました。

#### 一度の答え合わせで終わらせない

クイズの結果を見た後は、撮影カルテへ進みます。
知った好みを振り返り、次の撮影で試せるようにしました。

**相手の「好き」を知るほど、次の撮影が楽しみになる。**
そのフィードバックループを、機能と画面遷移の両方で支えています。

## 開発技術

### 活用した技術

#### API・データ

- **Firebase Authentication**
  - 匿名認証によるユーザー識別
  - メールアドレスやパスワードの入力を求めずに利用開始
- **Cloud Firestore**
  - プロフィール、ペア接続、撮影セッション、お気に入り、通知の管理
  - スナップショットの監視による画面へのリアルタイム反映
- **Cloud Storage for Firebase**
  - 撮影画像の保存・取得
- **Firebase Local Emulator Suite**
  - Authentication・Firestore・Storageを使ったローカルデモ環境

※現在のデモはFirebaseエミュレータを使用しています。通知はアプリ内通知です。

#### フレームワーク・ライブラリ・モジュール

| 技術 | 用途 |
| --- | --- |
| Flutter / Dart | アプリケーションの開発 |
| Flutter Web | ブラウザでの実行 |
| `camera` | カメラの起動・撮影 |
| `image` | 画像の向きの補正、切り抜き、縮小、JPEG変換 |
| `firebase_core` | Firebaseの初期化 |
| `firebase_auth` | 匿名認証 |
| `cloud_firestore` | データの保存・取得・リアルタイム監視 |
| `firebase_storage` | 撮影画像のアップロード・取得 |
| `image_picker` | プロフィール画像の選択 |
| `qr_flutter` | 招待コードのQRコード表示 |
| `device_preview` | スマートフォン画面を想定した表示確認 |

#### デバイス

- カメラを備えたPC
- ChromeによるFlutter Webの動作確認
- 通常ウィンドウとシークレットウィンドウを使った、二人分のユーザー操作の検証

### 独自技術

#### ハッカソンで開発した独自機能・技術

- **撮影セッション単位の写真共有**
  - 連続撮影した写真を、一つの撮影セッションとして共有します。
  - 全画像のアップロード完了後に共有状態を確定し、アルバムに表示します。
  - 関連ファイル：[photo_session_service.dart](flutter_app/lib/services/photo_session_service.dart)

- **複数のお気に入りからの3択クイズ生成**
  - 写真ごとのお気に入りと評価理由を保存します。
  - お気に入りからランダムに1枚を選び、その他の写真と組み合わせてクイズを構成します。
  - お気に入りの確定と撮影者への通知作成を、トランザクションでまとめて処理します。
  - 関連ファイル：[favorite_service.dart](flutter_app/lib/services/favorite_service.dart)

- **二人の操作をつなぐリアルタイム連携**
  - 相手のお気に入り送信をアプリ内通知に反映します。
  - 通知からクイズ、答え合わせ、撮影カルテまでをつなぎました。
  - 特に注力したファイル：[focus_shell.dart](flutter_app/lib/widgets/focus_shell.dart)

- **相手ごとの撮影カルテ・撮影ガイド**
  - 相手が選んだ写真と理由をまとめ、理由別に参考写真を見返せます。
  - 同じ相手との再接続後も、過去の撮影セッションを振り返れる構成にしています。
  - 関連ファイル：[shooting_chart_screen.dart](flutter_app/lib/screens/shooting_chart_screen.dart)
  - 関連コミット：`6dfd1d1`

- **接続解除後も残る、相手別アルバム**
  - 現在の接続状態と過去の写真の閲覧を分け、接続を解除しても、共有済みの写真を見返せるようにしました。
  - 関連ファイル：[partner_albums_screen.dart](flutter_app/lib/screens/partner_albums_screen.dart)
  - アクセス制御：[firestore.demo.rules](flutter_app/firestore.demo.rules)、[storage.demo.rules](flutter_app/storage.demo.rules)
